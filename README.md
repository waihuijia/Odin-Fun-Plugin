# Odin Fun Plugin丨麦子修复版

浏览器扩展:为 [odin.fun](https://odin.fun) 的持有人添加自定义备注与交易统计,支持可选的跨设备云同步。基于 [Kunsect/odin-users-remarks](https://github.com/Kunsect/odin-users-remarks) 二次开发。

A browser extension that adds custom holder remarks and trading statistics on [odin.fun](https://odin.fun), with optional cross-device cloud sync. Based on [Kunsect/odin-users-remarks](https://github.com/Kunsect/odin-users-remarks).

**安装 / Install:** Chrome Web Store 搜索 "Odin Fun Plugin丨麦子修复版"
